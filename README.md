# PQC-repo (大專生研究計畫)
後量子密碼學 (ML-DSA-44) 與傳統 ECC (SECP256R1) 混合雙簽章於車聯網 (V2X / VANET) 緊急車輛優先通行機制之實作。

---

# 執行說明
終端機路徑請設在專案根目錄。<br>
若要執行模組，請使用 `python3 -m <模組名稱>`，例如：
```bash
python3 -m OBU.main
```

---

# 執行流程

## 1. 環境設定
在專案根目錄建立 `.env` 檔案（若無則使用預設值）：
```env
CA_IP="127.0.0.1"
CA_PORT=57217
RSU_IP="127.0.0.1"
RSU_PORT=5005
```

## 2. CA 伺服器端
1. 產生 CA 根金鑰對（放入 `CA/keys/`）：
   ```bash
   python3 -m CA.gen_keys
   ```
2. 啟動 CA 伺服器監聽：
   ```bash
   python3 -m CA.listen
   ```

## 3. RSU 路側單元端
1. 向 CA 索取並配置根公鑰（自動存入 `RSU/keys/`）：
   ```bash
   python3 -m RSU.setup
   ```
2. 啟動 RSU 接收端（監聽 5005 埠，支援期末前提出機制）：
   ```bash
   python3 -m RSU.main
   ```
3. 按 `Ctrl+C` 可終止程式。

## 4. OBU 緊急車輛端
1. 向 CA 請求 ECQV 憑證並推導 ECC 私鑰（命令列參數指定車輛 ID，預設 `AMB-217`）：
   ```bash
   python3 -m OBU.setup AMB-217
   ```
2. 向 RSU 持續廣播緊急優先通行封包（可自訂車輛 ID 與發送頻率，例如每 3 秒發送一次）：
   ```bash
   python3 -m OBU.main AMB-217 3
   ```
3. 按 `Ctrl+C` 可終止程式。

# 系統特色與進度

### 已完成項目
- [ ] 採用原生 TCP Socket (埠 57217)，支援跨裝置 OBU 憑證註冊 (`0x57`) 與 RSU 根公鑰下載 (`0x67`)， 待測試。
- [x] **最大特色 ECQV**最車輛僅需 33 位元組重構點P_U 即可線上動態重構公鑰，大幅縮小傳輸體積。將後量子公鑰雜湊 {SHA256(pk_pqc)} 納入糾纏值e，解決剝離攻擊。
- [x] F1 碎片內含 BSM 載荷與 ECC 簽章，RSU 收到 F1 當下即可在 1~2ms 內完成初步驗證並切換為閃黃燈預熱。
- [x] 若後續碎片未在 80ms 內收齊，自動釋放快取回歸正常號誌。
- [x] 時間戳檢查雙重關卡，延遲超過 150ms 拒絕切換綠燈。
- [x] 零磁碟 I/O，快取上限設為 500 台車，且簽章驗證通過才寫入快取，防止快取毒化。
- [x] 避免重組完成後的備用分片造成幽靈超時誤報。
- [x] 進一步精簡封包。
